# rem0004 collection and global min requirements

**branch:** rem0004-collection-global-min-requirements · **status:** planning
**depends on:** rem0001, rem0002, rem0003 (and rem0000 for the tenant field)

## goal

a checklist every collection and global must meet, then apply it to all existing ones. this becomes the "definition of done" for new collections. link it from `CLAUDE.md` once final.

## checklist (draft)

- [ ] lives in `src/collections/<name>/` or `src/globals/<name>/` with colocated hooks, components, endpoints, and utils
- [ ] explicit `access` for every operation via `accessCheckResolver`, deny by default
- [ ] `admin.hidden` via `accessHiddenBySlug`
- [ ] `admin.group`, `useAsTitle`, `defaultColumns` set
- [ ] `createdBy` / `updatedBy` fields + hook (rem0003)
- [ ] audit log hooks (rem0002)
- [ ] `timestamps: true`
- [ ] sensitive fields have field-level access
- [ ] tenant field (after rem0000)
- [ ] types regenerated + migration committed
- [ ] seed in `src/seeds/` if the feature needs test data
